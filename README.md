# 성운과 성단 – 학습 웹앱

중학교 3학년 과학 ‘은하와 우주’ 단원 학습용 웹앱입니다.

학습은 아래 순서로 진행됩니다.

1. 학습목표
2. 도입퀴즈
3. 영상 학습
4. 개념 빈칸 학습 + 우주 사진 분류 탐구
5. 정리퀴즈
6. 오늘의 한줄 정리(산개·구상 성단 비교표 빈칸) + 재미있는 우주 이야기(사진 포함)
7. 선생님 확인

모든 단계를 마치면 **‘학습 완료!’ 팝업**이 뜹니다. 학생은 이 화면을 선생님께 보여 주고 확인을 받습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 학습 웹앱 본체 (고칠 필요 없음) |
| `config.js` | **선생님 설정 파일** – 영상 주소 |

## 1. 깃허브에 올리기 (GitHub Pages)

1. github.com에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
   - 이름 예: `nebula-cluster`
   - **Public** 선택 → **Create repository**
2. **uploading an existing file**을 누르고 `index.html`, `config.js`를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main / (root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   - 예: `https://아이디.github.io/nebula-cluster/`
   - 이 주소를 학생에게 안내하세요. QR 코드로 만들면 편합니다.

## 2. 영상 넣기·바꾸기

1. 깃허브 저장소에서 `config.js`를 누르고, 오른쪽 위 **연필(Edit)** 아이콘을 누릅니다.
2. `youtube: ""` 따옴표 안에 유튜브 주소를 붙여 넣습니다.

   ```js
   youtube: "https://www.youtube.com/watch?v=영상ID",
   ```

3. 필요하면 `title`(제목)과 `note`(안내 문구)도 바꿉니다.
4. **Commit changes**를 누르면 1~2분 뒤 학생 화면에 반영됩니다.
   - 반영이 안 보이면 학생 화면에서 새로고침하세요.

**영상 파일을 직접 올리는 경우**

1. 저장소에서 **Add file → Upload files**로 mp4 파일을 올립니다.
   - 파일 하나당 25MB 이하, 이름은 영문을 권장합니다.
2. `config.js`의 `file: "nebula.mp4"`처럼 파일 이름을 적습니다.

**영상을 2개 이상 넣는 경우**

`{ … }` 묶음을 쉼표로 이어 하나 더 추가합니다.

```js
videos: [
  { title: "영상 1", youtube: "https://youtu.be/…", file: "", note: "" },
  { title: "영상 2", youtube: "https://youtu.be/…", file: "", note: "" }
]
```

> 유튜브에서 ‘삽입 허용’을 꺼 둔 영상은 페이지 안에서 재생되지 않습니다. 이 경우 영상 아래에 있는 ‘유튜브에서 보기’ 링크로 볼 수 있습니다.

## 3. 학생 확인하기

학생이 모든 단계를 마치고 이름·학번을 쓴 뒤 **학습 완료하기**를 누르면 팝업이 뜹니다.

팝업에 나오는 내용은 다음과 같습니다.

- 이름, 학번
- 도입퀴즈, 개념 빈칸, 사진 분류, 정리퀴즈, 한줄 정리 점수
- 영상 시청 여부, 우주 이야기 읽음 여부
- 완료 시각

참고 사항

- 팝업을 닫았다가 다시 보려면 맨 아래 **완료 화면 다시 보기**를 누릅니다.
- 학습 진행 상황은 학생 기기의 브라우저에만 저장됩니다.
  - 새로고침해도 유지됩니다.
  - 다른 기기로 열면 처음부터 시작합니다.
